Privacy-First Architecture

How Orbit Works on Your Existing PiC Infrastructure

The system does not use facial recognition and masks individuals' faces and heads. Since no personal data is collected, stored, or processed, Orbit poses zero compliance risk under GDPR.

1. PiC Sensor

Real-Time Counting Capture

Builds directly on your existing Intelligent Counting PiC sensors positioned between zones to collect real-time movement data without requiring a disruptive hardware rip-and-replace.

2. Processing GPU (Edge AI)

Local Face Masking & 21 TOPS AI

Multiple PiC sensors connect to a single fanless Edge GPU powered by NVIDIA® Jetson Xavier™ NX. All deep-learning processing occurs 100% locally on the GPU—no visitor data is ever transmitted externally.

3. XML Output & Reporting

Simple XML & Ver 8.0 Analytics

Generates a clean, lightweight XML file with count data and anonymous unique visitor IDs—gathered automatically by Intelligent Counting software for Chord, Sankey, and Timeline reporting.

Edge Computing Unit

Palm-Sized Fanless Micro GPU

Engineered for silent, maintenance-free reliability (`115.70mm × 85mm × 46.50mm`). Connects multiple PiC sensors to a single processing unit via Gigabit LAN.
